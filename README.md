# 大埤爭霸戰

南一版六年級國語上下學期複習遊戲。沿用米白墨綠版面，GitHub版本免登入、免密碼，直接開啟就能玩。

🎮 [開啟遊戲](https://jerryyang2.github.io/dapi-chinese-arena/)

## 八大任務

1. 字詞競技場：國字、字音、詞義。
2. 課文偵探：人物、事件、主旨與因果。
3. 成語擂臺：成語與四字詞。
4. 句子修復站：句子重組、連接詞、錯別字。
5. 記憶配對賽：字音、詞義、人物與事件。
6. 修辭挑戰：六種修辭及表達效果。
7. 標點解碼站：補上標點與判斷用途。
8. 終極團隊賽：混合各類題型複習。

六上第1–12課共1,590項，六下第1–9課共1,162項，合計2,752項題目與配對回合。原有雙倍題庫保留，修辭與標點每課各4題；新例句為課文主題延伸自編，非課文原句。

支援單人、雙人、ＡＢＣＤ四隊同屏操作。各隊可用觸控、滑鼠或鍵盤，計分與錯題回顧均在同一台裝置進行，並非跨裝置即時連線。預設24題，可選12／24／40／60題或範圍全部。

上下學期紀錄分開儲存在瀏覽器，不蒐集姓名、不上傳分數。GitHub版使用獨立紀錄名稱，不影響同帳號下其他遊戲。

## 執行與驗證

```sh
python3 -m http.server 4174 --directory web
node scripts/verify-semesters.mjs
node scripts/build.mjs
```

`main`更新後，GitHub Actions會驗證題庫、建置並發布GitHub Pages。無執行期機密、登入服務或外部套件安裝需求。
